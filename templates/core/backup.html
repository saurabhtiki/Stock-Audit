How to restore a backup (IT / test server)
  1. Copy the zip to the test server's project folder.
  2. Run uv run python manage.py restore_backup the-backup.zip (with DJANGO_ENV=test or development).
  3. The old database and media are kept next to the new ones with “before-restore” in the name.
  4. On the live server it refuses unless --force is added, so data is never replaced by accident.
